Writing article workflow

1. Create a new file in this folder, for example: my-new-post.txt
2. Use this format:

Title: My New Post
Date: 2026-08-20

First paragraph here.

Second paragraph here.

3. Add a link entry in writing-list.js:
My New Post | writing-post.html?post=my-new-post

Notes
- The slug is the filename without .txt.
- You can paste plain text directly from Google Docs into the body.
- Leave a blank line between paragraphs.
